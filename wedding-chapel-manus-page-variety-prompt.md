Two fixes needed on the live site (littlechapel-2shatgdf.manus.space):

1) EVERY SUB-PAGE HEADER LOOKS IDENTICAL

Our Story, Packages, and Gallery (and likely Vendors, Reviews, FAQ, Contact too) all use the exact same header pattern: a dark charcoal/near-black block, left-aligned eyebrow + serif headline + subtext + one gold button, with a photo in a rounded rectangle on the right. Same layout, same dark background, same button style, same photo treatment, page after page. It reads as one template stamped 7 times rather than a real multi-page site.

Keep the overall brand (serif display type, warm gold accent, sage/cream palette) consistent across pages — that part is working. But vary the actual header treatment page to page. Some options to mix across the site:

- Alternate background tone: some page headers on warm cream/ivory instead of dark charcoal, with dark text instead of white
- Vary photo placement/treatment: full-bleed background photo with a dark gradient overlay behind the text (instead of a boxed photo on the right) for some pages; no photo at all for others, just strong typography on a warm color field
- Vary layout structure: not every page needs left-text-right-image — try centered headlines for some (e.g. FAQ, Contact), or a full-width photo banner with text overlaid at the bottom for others (e.g. Gallery)
- Vary height/scale: sub-pages don't all need a near-full-viewport header like the homepage — some can be shorter/more compact

Goal: each page should feel distinct at a glance while still obviously belonging to the same site. Show me Our Story, Packages, and Gallery with three visibly different header treatments before applying a similar pattern to the remaining pages (Vendors, Reviews, FAQ, Contact).

2) ADD AN EXPLICIT "HOME" LINK TO THE TOP NAV

Right now the only way back to the homepage is clicking the logo. Add a visible "Home" text link as the first item in the top navigation bar, alongside Our Story, Packages, Gallery, Vendors, Reviews, FAQ — so it's not logo-only navigation.
