# Restorix Badge Icons — 5 Category Emblems (nanobanana prompts)

Shared visual language across all 5: a shield-shaped badge with a beveled 3D border (metallic gradient edge, dark/black interior fill), a single bold icon centered inside, matching classic video-game achievement badge style (2K-style). Each category gets its own bevel/border color; the icon itself renders in white or a bright tint of that same color for contrast against the black interior. Tier level is NOT baked into these images — these are the base category emblems only; tier variation (numerals/rings/intensity) gets layered on programmatically in code afterward.

Generate each of the 5 below as a separate image, isolated on a plain/transparent background, high resolution, icon-only (no text, no title, no description baked into the image — those render separately in the UI).

---

## 1. Dials — emerald green

Design a shield-shaped achievement badge icon. Beveled 3D metallic border in emerald green (#10b981 range), glossy/gem-like edge highlights. Interior fill solid black. Centered icon: a bold, simple phone/headset silhouette (a classic "call" icon — a phone receiver or headset shape), rendered in bright white or pale green, with a subtle glow. Flat/vector-clean icon style, not photorealistic. No text, no numbers, no background scene — icon and badge only, isolated on transparent background.
